# Anime Streaming Frontend

This is a sample anime streaming website frontend built with React.

## Features
- Browse a list of popular anime (sample data)
- View anime details and stream sample video
- Modern, responsive design

## Getting Started

1. Install dependencies:
   ```sh
   cd frontend
   npm install
   ```

2. Start the dev server:
   ```sh
   npm start
   ```
   Visit http://localhost:3000

---
This is a sample UI — you can connect this frontend to a backend or API for real anime data.
